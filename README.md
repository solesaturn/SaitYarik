# Laitys — интернет-магазин электроустановочных изделий

Розница оплачивает заказ на сайте. Бизнес отправляет корзину на ручной расчёт.

Сайт закрыт от индексации, пока владелец не включит её в админке.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma + SQLite (на проде лучше PostgreSQL)

## Запуск

```bash
cp .env.example .env
npm install
npm run db:reset
npm run dev
```

Откройте http://localhost:3000

Вход в админку: `/account` → e-mail `kamalovaar@gmail.com`, пароль из `ADMIN_PASSWORD` (по умолчанию при seed: `ChangeMeLaitys`). Смените пароль сразу.

## Переменные

- `DATABASE_URL`
- `ADMIN_EMAIL`, `ADMIN_PASSWORD` — только для seed
- `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` — онлайн-оплата
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` или `NOTIFY_WEBHOOK_URL` — уведомления о заказах и заявках
- `NEXT_PUBLIC_SITE_URL`

Ozon Pay и калькулятор Ozon Доставки — второй этап, когда будут доступы.

## Что делает владелец без разработчика

- Товары: цена, остаток, фото, характеристики, Excel-импорт
- Заказы B2C и статусы
- Заявки B2B, файлы, выгрузка CSV
- Контакты, FAQ, сертификаты PDF

## Редактор и публикация

В разделе «Товары» можно создать новый товар или изменить существующий: формат,
категории, характеристики, гарантию, SEO и галерею с подписями. Первое фото — обложка;
кнопки «Раньше / Позже» меняют порядок. Загрузка преобразует фото в квадратный WebP
1600 × 1600 с полями. Качество исходника по-прежнему важно.

«Сохранить черновик» не меняет витрину. «Предпросмотр» сначала сохраняет черновик
и открывает закрытую для посетителей страницу. «Опубликовать» применяет изменения.
Тексты и изображения главной редактируются в разделе «Тексты и FAQ» с таким же
циклом. Вопросы тоже сохраняются в черновик и публикуются отдельной кнопкой.
Быстрая цена/остаток в списке товаров, импорт CSV и контактные настройки по-прежнему
обновляются сразу — для предварительной проверки товара используйте полный редактор.

Чтобы добавить модуль в конструктор, выберите формат «Модуль для рамки», один пост,
цвет и настройку «Показывать модуль в конструкторе», затем опубликуйте. Код менять
не нужно. Цветовые варианты с общим артикулом и суффиксами WH/GY/BK сохраняют выбор
при смене цвета; если варианта нет, выбирается первый доступный модуль нового цвета.

Черновики хранятся в SiteSetting (`draft:product:<id>`, `draft:home`, `draft:faqs`),
настройка конструктора — в служебном поле attrsJson `_constructorEnabled`.
Миграция схемы не требуется. Фотографии из редактора хранятся в базе как WebP data URL,
поэтому загрузка работает и на сервере с файловой системой только для чтения.

Для существующей базы выполните `npm run db:update-presentation` с её DATABASE_URL:
команда заменяет только исходные товарные галереи на подготовленные WebP, не трогая
цены, остатки и пользовательские загрузки. В комплектной seed.db это уже сделано.
Для S1P-GY, S1P-WH, S2-BK, S2-WH и S2P-GY исходных лицевых фотографий нет:
используется обозначенная заглушка, доступные снимки сзади сохранены в галерее.

Проверки: `npm test`, `npm run build`.
